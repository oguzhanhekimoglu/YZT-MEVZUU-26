# Third-Party Licenses

Python dependency versions are locked in `uv.lock`. Each installed distribution's authoritative license metadata and bundled license files remain the source of truth. Key runtime components include FastAPI, Pydantic, aiosqlite, httpx, PyYAML, NumPy, FAISS CPU, sentence-transformers, transformers, PyTorch, pypdf, python-docx, orjson and structlog.

Before redistribution, generate a dependency bill of materials from the locked environment and include every package's bundled notice. This inventory does not relicense third-party packages or the aviation documents.
